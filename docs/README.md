## 二、阅读顺序建议

```text
README.md（项目主页）
   └── 01-项目简介.md        ← 先建立规则与情境的完整认知
         └── 02-预算规划-A_B方案.md   ← 再看成本、工期与执行方案怎么算出来
               └── 03-最终汇报文档.md  ← 最后是汇报总纲：一页纸总览 ＋ 全事件台账
                     └── 04-致甲方演说稿.md  ← 上场前照读这一份
```

**按场景选择**：

| 场景 | 建议读什么 |
| --- | --- |
| 初次了解项目 | 本文 → `01 项目简介` |
| 复核成本与工期 | `02 预算规划` 第一／二／三节 |
| 准备书面提交 | `03 最终汇报文档` 第一、九、十节 |
| 准备 3 分钟路演 | `03 最终汇报文档` 第十一节 ＋ `04 致甲方演说稿` 第一、四节 |
| 应对评委追问 | `03 最终汇报文档` 第十二节（追问应答）＋ `04 致甲方演说稿` 第四节 |

## 三、统一口径基准（四份文档共用）

| 项目 | 基准值 |
| --- | --- |
| 承接标段 | A 段 900 米 ＋ B 段 800 米 ＝ **1700 米**（宽 6 米 × 高 6 米） |
| 工期 | **83 / 90 天**（施工 73 ＋ 瘟疫延期 10，余 7 天） |
| 工程造价 | **1,511,560** 秦半两（含 4 座烽火台） |
| 合计支出 / 结余 | **1,651,560（82.6%）** ／ **348,440** |
| 执行记录 | **1 个 ×**（020 页试火，缺「火镰」） |
